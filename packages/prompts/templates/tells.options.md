## user
Overused patterns in option sets, each with a better alternative:

- Stock ideas any competitor would list first (a loyalty scheme, an app, a referral programme) → the bet only this situation makes possible
- Options that differ only in channel, price or audience → genuinely different bets
- Names built from stock parts (a dropped vowel, a -ly or -ify ending, a "hub") → a name from the option's own metaphor domain
- Ideas or names that also turn up in plain, unseeded runs → a new seed or a new direction
- Pitches that list features → why someone would choose it
