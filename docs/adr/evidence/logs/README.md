# Logs kept as evidence

Most logs behind the decision records were left out of the repository ([the evidence index](../README.md) says what was kept). These sets were brought in unchanged, on 2026-10-19 and 2026-10-21, because a record's figures or a backlog row rest on them alone. They are kept byte for byte: the repository's `.gitattributes` leaves their line ends as written. (Until 2026-10-21, `gate-build.log` and `32-gate-build.log` were stored without the carriage returns that end three of their progress lines. On 2026-10-21 every file in these sets had the same SHA-256 as its original under Temp.)

- [ci-timing-2026-10-17/](ci-timing-2026-10-17/): the runs behind [ADR-0103](../../0103-adr-log-rule-and-ci.md)'s Later note of 2026-10-17 on the five renderer tests that held a render or a read to a fixed time. The numbered logs are the runs at normal speed, with 32 busy processes, and throttled 4 and 20 times, of the old tests and the new; `mutations/` holds the runs with each guarded behaviour taken out, with their summaries; `gate-*` and `32-gate-*` are the gate's logs; `adr-note.md` is the note as drafted. The scripts that made them are kept beside them. `run-mutations*.sh` copy the old tests to `packages/runner/test/old-pages-a3bba97.test.ts`; that file is `git show a3bba97:packages/runner/test/pages.test.ts`, so it is not kept here.
- [ci-run-39152075629/](ci-run-39152075629/): from the Windows job of CI run 39152075629 (the D2 branch at f46726f, 2026-10-18), the one that failed C5's 120 s wait for its next turn (the backlog row "Known Windows timing flake"). `byway-e2e-server.log` is the job's server log and `c5-error-context.md` the failed test's page as Playwright recorded it. GitHub keeps the run's own copies until 2026-11-01. Brought in on 2026-10-21: the screenshot Playwright took when the test failed (`c5-test-failed.png`, 254 KB) and the test's own trace, each step it took and waited on with its times (`c5-test.trace`, 463 KB, from the trace's `test.trace`). The rest of the trace was left out: its zip is 141 MB, almost all of it the page's screencast frames, and its browser and network records are 2.6 MB and 0.55 MB.
- [ci-run-39097581622/](ci-run-39097581622/): the log of the Windows job of CI run 39097581622, attempt 1 (`windows-failed.log`, 119 KB), whose C1 demo run failed with "Target page, context or browser has been closed": the failure behind [ADR-0106](../../0106-a-late-close-retires-the-renderers-browser.md). Brought in on 2026-10-21, before GitHub stops keeping the run's logs; ADR-0106's note of 2026-10-18 had left it out.
