# The claims oracle's draws with the old generator (2026-10-21)

The data and scripts behind [ADR-0097](../../../0097-a-step-takes-in-only-what-its-prompt-shows.md)'s Later note on the claims oracle's random answers: two refuters of the check of B1's CLAIMS-1 ([reports/b1-checks-2026-10-21.md](../../reports/b1-checks-2026-10-21.md)), each in a clone of the branch at 481b2e5 (00401a0 on main since the history rewrites of 2026-10-21), ran the ported oracle at the measurement's size (26 seeds of 40,000 tries, 20,695 admitted variants, 12 runs each) with the old generator product (`seed * 1103515245`, `OLD_LCG`), counting the draws of each variant. The re-check of that day recomputed the note's figures from this data. They were kept only in the session's scratchpad under Temp; Claude brought them in on 2026-10-21, unchanged. The probes ran inside the clones, against the oracle as it stood there, so they record what was run; they are not tests that run today.

- [refute-c/](refute-c/): `oracle.diff` is the probe's change to `scripts/test/claims-oracle/oracle.ts` (a per-variant draw log, and the old product when `OLD_LCG` is set); `draws.test.ts` writes the corpus's draw log and problem report (`draws-old-full.json`, at the measurement's size, its run in `full-run.log`; `draws-old-3000.json` and `draws-new-3000.json`, the unit run's 118 variants with the old and the exact product); `ana-full.mjs` and `ana.mjs` count from them the draws on a cycle's states and the variants whose draws repeat a state; `cyc.mjs`, `where.mjs` and `ext.mjs` find the old generator's cycles from the oracle's seeds alone. `pick.test.ts` judges C2 variants 2502 and 2677 at 2,700 answer seeds each, with each product (`pick-r.txt`; its runs in `pick-old.log` and `pick-new.log`): with the exact product, 2502 is reported E-REACT-CLAIM-BUT-NEVER-SHOWN at 6 seeds, and 14 with the old.
- [refute-d/](refute-d/): the second refuter's probe, written separately from the first: `oracle.diff` (a draw count and a repeated-state count per variant), `draws-probe.test.ts`, its output at the measurement's size (`full-old-d.json`, its run in `full-old-d.log`) and at the unit run's (`small-old.json` and `small-new.json`, with each product), and `ana-d.mjs`, which gives the same figures from `full-old-d.json`. `full-old-unfinished.log` is a run of the same probe that printed only its start.

Not kept: the refuters' clones, and an earlier run at that size with the old product, of 2026-10-19 (`full-old.json`, 1.4 MB, with the scripts of that day); its problem report is the same as in `draws-old-full.json` and `full-old-d.json`.
