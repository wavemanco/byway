Labels key on the ADR-0041 frozen snapshot (recipe, prompt template versions, models, engine, renderer, fallback policy), not on the recipe hash alone. The lineage check must not trust an `exposure.jsonl` restored from an older backup; it cross-checks against the ledger's judging calls. The review's other activation prerequisites (treatment-fidelity dry run, instrument separation, operational governance, independent metric validation) restate ADR-0041/0044/0052/0054/0055 and apply before confirmatory collection. The study engine also needs, before the first study run (the pilot or any development-brief tuning, well before this registry's first entry), the two protocol requirements ADR-0102 leaves to it: the served-model check that halts a run when the returned model differs from the profile (§5.1), and counting a second refusal as Class Q "provider refusal" (§5.2), from the ledger's declined and retryOf entries and the model-declined events. The public Program Registry (ADR-0046, CR3), which is separate from the product's label registry in registry.ts, is also to hold the research roadmap (ladder rungs, candidate Paper 2 domains, comparator-selection criteria), with the deferred arms and measures: ADR-0061's GPT worker arm ("logged in the roadmap"), ADR-0035's deferred ablations, and protocol v1.1 Appendix B.2 item 12.
