## LENS useful
SUMMARY: Read as a decision-maker, the protocol is carefully labeled in places. 04 has a real corrections log and evidence gaps, and the README states its limits. But several load-bearing problems would mislead an adopter or break the protocol's own logic.

1. **Success metrics reward evasion.** C3, C5 and C8 define success as "not flagged as AI." That is the evasion objective the README disclaims. C8 also becomes the home of the SEO pattern that 04 rejected for evasion risk, and C5 has no consent, likeness or provenance guard for synthetic people and voices.
2. **Loops are unbounded and there is no cost model.** Critic-loop failure handling contradicts itself across 01, 02 and 03. Backtracks have no limit. C1's only budget metric ("critic under 10% of output tokens") ignores the image-heavy input that dominates critic cost.
3. **CRITIC's reliability caveat is buried.** The default CRITIC mode (OK, no references) is exactly the unanchored judging that the protocol's own evidence puts near chance. 05 says "whether CRITIC works at all depends on this," but the README never says so. The "rank against references" rule is labeled evidence-backed although the protocol itself cites counter-evidence (Tripathi).
4. **C7 breaks hard invariants.** Its reviewer sees code and acceptance criteria and judges correctness. That is the VERIFY block 05 files as off-path, and the mutation-test sub-loop is beyond the article.
5. **Several success criteria are circular.** C1, C3 and C6 judge success with the same critic the loop optimized against.
6. **Some configurations are presented more prominently than their evidence supports.** C5 Video and Still modes were never swept on their own. C8 rests on anecdote and unverified market figures. SOURCES holds counter-evidence (Aldous, Meguellati, Purcell, Girotra) that the cards leave out.
7. **The scoring rubric has problems.** It has no anchors, and the Evid score mixes evidence of pain with evidence that the fix works. Workslop Pull is inconsistent with C2's score for the same reason. Rejected cases were never scored, so the rubric did not actually decide which configurations exist.
